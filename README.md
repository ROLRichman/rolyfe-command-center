# RO’Lyfe Master Hub™

The central public entrance to the RO’Lyfe ecosystem. This mobile-first GitHub Pages site organizes independent RO’Lyfe platforms into four clear departments without merging their repositories, code, data, or deployments.

## Public website

https://rolrichman.github.io/rolyfe-command-center/

## Four department front doors

1. **Funding & Real Estate** — RO’Lyfe Funding & Execution Hub, business funding resources, property research, Auction Capital Machine, and contract documents.
2. **Trading & Markets** — ROlyfe Trading Calculator Pro is the primary front door. Chart Wars and Scanner Hub remain sections within that product; the Trading Intelligence Classroom and Tactical Intelligence Center remain separate specialist platforms.
3. **Education & Family Wealth** — Family Wealth Academy and the RO’Lyfe learning/video resources.
4. **Entertainment** — RO’Lyfe Entertainment Network, Live Sports Center, Pool, and eGaming.

## Project boundaries

- This repository owns the Master Hub navigation experience.
- Each destination remains in its own repository and keeps its own deployment and history.
- The hub links to destinations; it does not copy their source code or claim that their APIs, AI services, databases, or live data are connected.
- The property research dock remains included as an existing shared integration.
- Social profile links should point to the user's actual public profiles. TikTok is linked to @richman_rolyfe; the Facebook page link is intentionally pending its exact public URL.

## Design and accessibility

- Responsive layout for phones, tablets, and desktop.
- Four primary department cards with clear calls to action.
- Extended platform directory for specialist tools.
- No backend, login, or API keys required for the static directory page.

## Publish

GitHub Pages should publish the repository's main branch from the root (/). After a commit, confirm the Pages deployment and test the public URL on mobile and desktop.
