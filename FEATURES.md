# Feature inventory

## Implemented in the Command Hub UI
- Responsive dark interface with orange accent
- Platform cards linking to existing projects
- Text search and category filtering
- Mobile-friendly layout and keyboard-operable controls
- Explicit status copy preventing false claims about unconfigured integrations

## Not yet implemented
- Shared authentication or single sign-on
- Real-time platform health checks
- AI-provider routing or shared conversation memory
- Email or SMS delivery
- Webhook receiver or event database
- Private task inbox and user-specific preferences

These items require backend configuration, provider credentials, security review and end-to-end tests.
